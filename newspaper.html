FEATURE / STUDENT LIFE

Small projects make new concepts easier to understand.

Reading about a programming concept is useful, but trying it in a small project makes the idea more concrete. A simple page can teach you about structure, spacing, alignment and responsive behaviour.

When something does not work, checking the browser and changing one thing at a time is a good way to find the problem.

PROGRAMMING / 01

Keep practising the basics

Variables, conditions, loops and functions appear in many programs. Getting comfortable with them makes it easier to approach larger problems.

WEB / 02

Make pages work on small screens

A layout should remain readable on a phone as well as a laptop. Flexible widths and media queries help with this.
