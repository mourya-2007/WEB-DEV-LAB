P13 / CSS LAYOUT SYSTEMS

Flexbox and Grid

Both are used to arrange elements on a page. The main difference is the type of layout each one handles well.

01 / FLEXBOX — ONE DIMENSION

Navigation bar

Flexbox is useful when items need to be arranged in a row or a column, with control over alignment and spacing.

Which one should I use?

Use Flexbox for a row or column of items. Use Grid when you need to arrange items in both rows and columns. It is also fine to use both in the same page.
